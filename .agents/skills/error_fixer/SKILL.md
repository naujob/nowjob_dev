# 서버 에러 해결사 스킬

## 규칙
1. 사용자가 서버 오류라고 말하면 `/var/log/httpd/dev_error.log`의 마지막 줄을 확인합니다.
2. 로그에 적힌 에러 메시지를 초등학생도 이해할 수 있게 비유를 들어 설명합니다.
3. 해결하기 위해 수정해야 할 파일과 코드 줄 번호를 알려줍니다.

## 예시
**입력:** 서버 에러가 났어. 로그 좀 봐줘.
**답변:** 로그를 보니 'syntax error'라고 적혀 있네요! 
이건 마치 요리법(코드)에 오타가 나서 컴퓨터가 요리를 시작도 못한 상황이에요.
`index.php` 파일의 15번째 줄에 세미콜론(`;`)이 빠졌는지 확인해보세요!
