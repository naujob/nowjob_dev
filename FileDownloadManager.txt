# iOS 웹-네이티브 브릿지 파일 다운로드 구현 결과

웹뷰에서 JavaScript 호출을 통해 전달받은 URL과 파일명을 처리하여, 파일 종류에 따라 기기의 갤러리에 직접 저장하거나 iOS 공유 시트(UIActivityViewController)를 띄워 다운로드 및 관리를 가능하게 하는 구현을 마쳤습니다.

## 변경 사항 및 추가된 기능

### 1. Info.plist

- 사진 앨범에 이미지를 직접 저장할 수 있도록 권한 설명 설정을 업데이트하였습니다.
    - `NSPhotoLibraryAddUsageDescription` 권한에 맞춰 다운로드된 이미지 저장 사유를 설명합니다.

### 2. FileDownloadManager.swift [NEW]

- `URLSession` 기반의 포그라운드 다운로드 로직을 제공하는 싱글톤 클래스입니다.
- 확장자 기반으로 미디어 파일(이미지/비디오)과 문서 파일을 분류합니다.
- 미디어 파일의 경우 `PHPhotoLibrary`를 사용하여 시스템 앨범에 리소스를 생성하는 역할을 전담합니다.

### 3. ViewController.swift [MODIFY]

- `"downloadFile"` 브릿지 명칭을 `WKUserContentController`에 등록하였습니다.
- `userContentController(_:didReceive:)` 메소드에서 수신한 메시지 바디를 파싱하여 다운로드 태스크를 수행합니다.
- 다운로드 시작 시 네이티브 로딩 다이얼로그(`UIActivityIndicatorView`)를 사용자에게 표출합니다.
- 완료 후:
    - **이미지/비디오 확장자인 경우:** `PHPhotoLibrary` 사용 권한을 검사 후 허용되었을 때 갤러리에 저장하고 성공 알림을 띄웁니다. 거부되었을 시 설정 화면으로 이동할 수 있는 Alert 창을 제공합니다.
    - **일반 문서인 경우:** `UIActivityViewController`를 실행하여 사용자가 '파일에 저장', '공유', 'AirDrop' 등을 직접 선택할 수 있도록 사용자 편의를 도모합니다.

## 검증 방법

1. iOS 디바이스나 시뮬레이터에서 앱을 실행합니다.
2. 웹의 개발자 콘솔 등을 통하여 다음 JavaScript 스크립트를 작동시킵니다:
    
    ```jsx
    window.webkit.messageHandlers.downloadFile.postMessage(JSON.stringify({
        url: "<https://www.w3.org/WAI/ER/tests/xhtml/testfiles/resources/pdf-test.pdf>",
        fileName: "test_document.pdf"
    }));
    ```
    
3. UIActivityViewController(공유 시트)가 팝업되어 정상적으로 문서를 저장할 수 있는지 확인합니다.
4. 이미지 파일 주소로 동일하게 다운로드를 시도하여 권한 동의 여부를 묻는 팝업 및 사진 앱 내 저장을 검증합니다.
