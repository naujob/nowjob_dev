## 🔐 SNS 회원가입 경로

### 개인회원 (MEM)

#### 1. SNS 로그인 콜백
- **함수**: `Member::kakao_login_callback()` / `Member::naver_login_callback()` / `Member::apple_login_callback()`
- **위치**: `application/shop/controllers/member.php`
- **처리 내용**:
  - SNS 로그인 실패 시 → `Member::join_sns_start()` 호출
  - SNS 정보를 세션에 저장 (`sl_type: "JOIN"`, `sl_step: "SNS"`)

#### 2. SNS 회원가입 시작
- **함수**: `Member::join_sns_start()`
- **위치**: `application/shop/controllers/member.php` (533-608번 줄)
- **처리 내용**:
  - URL 파라미터에서 SNS 정보 수집 (join_key, join_type, username, email, gender, phonenum, birthyear, birthday)
  - 전화번호 중복 체크 (`checkDuplicatePhoneForSns()`)
  - 세션에 SNS 정보 저장 (`sl_type: "JOIN"`, `sl_step: "SNS"`)
  - **리다이렉트**: `/member/join_start?join_type=sns`

#### 3. 회원가입 시작 페이지
- **함수**: `Member::join_start()`
- **위치**: `application/shop/controllers/member.php` (611-645번 줄)
- **페이지**: `application/shop/views/mobile/member/join_start.php`
- **처리 내용**:
  - `join_type != "sns"`인 경우에만 기존 로그 삭제
  - NICE 본인인증 데이터 생성 (`getNiceEncData()`)
  - 회원구분 선택 화면 표시

#### 4. 개인회원 클릭 이벤트
- **위치**: `application/shop/views/mobile/member/join_start.php` (338-367번 줄)
- **처리 내용**:
  - `join_type === 'sns'` 확인
  - `/member_proc/join_auth` 호출 (type: "MEM")
  - **리다이렉트**: `/member/join_mem_step1`

#### 5. 회원가입 인증 처리
- **함수**: `Member_proc::join_auth()`
- **위치**: `application/shop/controllers/member_proc.php` (574-622번 줄)
- **처리 내용**:
  - 회원 타입 저장 (`AUTH_TYPE` 세션: "MEM" 또는 "COMP")
  - 인증 진행 로그 저장 (`sl_step: "개인_인증진행"` 또는 `"기업_인증진행"`)

#### 6. 개인회원 스텝1
- **함수**: `Member::join_mem_step1()`
- **위치**: `application/shop/controllers/member.php` (695-798번 줄)
- **페이지**: `application/shop/views/mobile/member/join_mem_step1.php`
- **처리 내용**:
  - SNS 정보 확인 (`getSiteLog("JOIN", "SNS")`)
  - **SNS 정보 있으면**:
    - 임시 ID/PWD 생성 (uniqid)
    - 로그 저장 (`sl_type: "JOIN_MEM"`, `sl_step: "스텝1"`)
    - **리다이렉트**: `/member/join_mem_step2`
  - **SNS 정보 없으면**:
    - 비밀번호 입력 화면 표시

#### 7. 개인회원 스텝2 (주소 입력)
- **함수**: `Member::join_mem_step2()`
- **위치**: `application/shop/controllers/member.php` (801-812번 줄)
- **페이지**: `application/shop/views/mobile/member/join_mem_step2.php`
- **처리 내용**:
  - 스텝1 데이터 검증
  - **자동 리다이렉트**: `/member/join_mem_step3` (페이지 로드 시)

#### 8. 개인회원 스텝3 (약관 동의)
- **함수**: `Member::join_mem_step3()`
- **위치**: `application/shop/controllers/member.php` (814-842번 줄)
- **페이지**: `application/shop/views/mobile/member/join_mem_step3.php`
- **처리 내용**:
  - 약관 동의 화면 표시
  - 동의 후 `/member_proc/join_mem_step3` 호출

#### 9. 개인회원 스텝4 (이력서 작성)
- **함수**: `Member::join_mem_step4_1()` ~ `join_mem_step4_4()`
- **페이지**: `application/shop/views/mobile/member/join_mem_step4_*.php`
- **처리 내용**:
  - 이력서 정보 입력
  - 각 스텝별 데이터 저장

#### 10. 최종 회원가입 처리
- **함수**: `Member_proc::join_mem_step4_4()` (proc_type: "ALL")
- **위치**: `application/shop/controllers/member_proc.php`
- **처리 내용**:
  - SNS 정보 확인 (`getStepTempData("JOIN", "SNS")`)
  - **SNS 경로**: SNS 정보에서 이름, 전화번호, 성별, 생년월일 추출
  - **일반 경로**: 본인인증 정보에서 추출
  - 회원 정보 DB 저장
  - 로그인 처리

## 🔄 데이터 흐름 요약

### SNS 경로
```
SNS 로그인 → join_sns_start() → join_start?join_type=sns 
→ 회원구분 선택 → join_auth() → join_mem_step1() / join_comp_step3()
→ SNS 정보 확인 → 자동 리다이렉트 → 최종 회원가입 처리
```

### 일반 경로
```
join_start() → 회원구분 선택 → join_auth() → NICE 본인인증 
→ nice_success() → 본인인증 정보 저장 → 각 스텝 진행 → 최종 회원가입 처리
```

### 핵심 분기점
1. **SNS 정보 확인**: `getSiteLog("JOIN", "SNS")` 또는 `getStepTempData("JOIN", "SNS")`
2. **데이터 추출**: SNS 경로는 SNS 정보에서, 일반 경로는 본인인증 정보에서 추출
3. **자동 리다이렉트**: SNS 경로에서 특정 스텝 건너뛰기
