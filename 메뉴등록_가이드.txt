========================================
PC배너광고 클릭수 관리 - 메뉴 등록 가이드
========================================

【구현 완료 파일】
1. application/admin/controllers/admin/ad.php - 광고 컨트롤러 신규 생성
2. application/admin/views/admin/ad/pc_banner_click_list.php - 관리자 뷰 신규 생성
3. application/common/models/recruitmodel.php - getAdClickLogList() 메서드 추가
4. st_ad_click_log.sql - DB 테이블 생성 (이전 단계)

【메뉴 등록 단계】
1. 다음 SQL을 실행하여 전화걸기/지원하기 관리(am_idx=503) 정보 확인:

   SELECT am_idx, am_parent, am_depth, am_name, am_url, am_sort
   FROM st_admin_menu
   WHERE am_idx = 503;

2. 위 조회 결과에서 'am_parent' 값 확인
   예: am_parent = 466 이면, 아래의 [am_parent값]을 466으로 변경

3. 다음 SQL 실행하여 메뉴 등록:

   INSERT INTO st_admin_menu
   (am_parent, am_name, am_url, am_depth, am_sort, am_status, am_hidden)
   VALUES
   ([am_parent값], 'PC배너광고 클릭수 관리', '/admin/ad/pc_banner_click_list', 3, 504, 'Y', 'N');

   예시) am_parent=466인 경우:
   INSERT INTO st_admin_menu
   (am_parent, am_name, am_url, am_depth, am_sort, am_status, am_hidden)
   VALUES
   (466, 'PC배너광고 클릭수 관리', '/admin/ad/pc_banner_click_list', 3, 504, 'Y', 'N');

【권한 설정】
- Admin.php의 getAdminMenuList() 함수에서 이미 role_site = 'Y' 그룹에
  am_idx 503이 포함되어 있으므로, 같은 그룹에 속하는 새 메뉴도
  같은 권한 그룹(role_site)으로 관리됨.
- 별도 권한 설정 불필요

【URL】
http://[domain]/admin/ad/pc_banner_click_list

【테스트】
1. 관리자 로그인 후 메뉴 확인
2. '전화걸기/지원하기 관리' 메뉴 아래에
   'PC배너광고 클릭수 관리' 메뉴 표시 확인
3. 클릭하여 페이지 로드 확인
